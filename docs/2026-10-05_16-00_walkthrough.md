## 1. Resumen de la Solicitud

El usuario solicitó que la búsqueda **incluya las palabras acentuadas**, de modo que cualquier consulta por palabras clave encuentre las actividades sin importar si el usuario escribe con tildes o sin tildes (por ejemplo, al escribir `"habitos"` debe encontrar `"Hábitos"`, y al escribir `"método"` debe encontrar `"Metodo"`).

## 2. Cambios Implementados

### A. Módulo Central de Normalización: [`services/searchUtils.ts`](file:///Users/francisco/Herd/Mandala-Copilot/services/searchUtils.ts)
Se implementaron funciones puras y reutilizables basadas en descomposición canónica Unicode (`NFD`):
```typescript
export const normalizeText = (text?: string | null): string => {
  if (!text) return '';
  return text
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .toLowerCase()
    .trim();
};

export const matchTextAccentInsensitive = (
  targetText?: string | null,
  queryText?: string | null
): boolean => {
  if (!queryText || !queryText.trim()) return true;
  if (!targetText) return false;

  const normTarget = normalizeText(targetText);
  const normQuery = normalizeText(queryText);

  // Subcadena directa
  if (normTarget.includes(normQuery)) return true;

  // Multi-término (todas las palabras presentes)
  const queryTokens = normQuery.split(/\s+/).filter(Boolean);
  if (queryTokens.length > 1) {
    return queryTokens.every((token) => normTarget.includes(token));
  }

  return false;
};

export const matchAnyTextAccentInsensitive = (
  targets: (string | null | undefined)[],
  queryText?: string | null
): boolean => {
  if (!queryText || !queryText.trim()) return true;
  return targets.some((target) => matchTextAccentInsensitive(target, queryText));
};
```
